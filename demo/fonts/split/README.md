These web font files were retrieved on 2026-11-01 from URLs returned by the Google Fonts CSS API for DM Sans and Noto Sans JP, with weights 400, 600, and 700. `SOURCE_MANIFEST.json` records the original URL, size, and SHA-256 of each downloaded WOFF2 file.
